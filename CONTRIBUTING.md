# Contributing
The current goal of the project is to create a functionally equal implementation of iggy, e.g. piggy should just be able to be dropped in place of iggy and the program just work. Therefore all contributions should be focused on aiding implementation or correcting the accuracy of the existing implementation as faithfully to the original as possible, binary parity is not a massive concern but that doesn't mean the implementation should deviate from original functions, data and behaviour.

- Pull requests that add new features will be ignored.
- **DO NOT** use RAD code or headers in this repo, the goal for this project is a recreation based on iggy without packaging any code written by RAD or their binaries, assets.
